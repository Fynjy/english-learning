# Хранители Глаголов: Путь к Ородруину 🧝‍♂️💍

Интерактивная игра для изучающих английский язык по мотивам «Властелина Колец». Игроку нужно правильно вводить три формы неправильных английских глаголов, чтобы пройти по сюжету — от Шира до Роковой Горы.

## Структура проекта

```
english-learning/
├── lord_of_verbs.html    # Исходный (полностью самостоятельный файл)
├── index.html            # Собранный файл (генеруруется)
├── README.md             # Этот файл
├── src/
│   ├── template.html     # HTML-шаблон без данных карточек
│   └── build.sh          # Скрипт сборки
└── questions/
    ├── 01_find.json      # Карточка: глагол FIND
    ├── 02_go.json        # Карточка: глагол GO
    ├── 03_run.json       # ...
    └── 35_sleep.json     # Карточка: глагол SLEEP
```

## Сборка

Из корня проекта запустите:

```bash
./src/build.sh
```

Скрипт:
1. Читает `src/template.html`
2. Загружает все JSON-файлы из `questions/` в порядке сортировки
3. Формирует из них массив JSON
4. Заменяет плейсхолдер `CARDS_DATA` в шаблоне на этот массив
5. Записывает результат в `index.html`

## Добавление новой карточки

1. Создайте JSON-файл в `questions/` с именем вида `NN_verb.json` (для сохранения порядка сортировки), например:

```json
{
  "chapter": "Глава X: Название главы",
  "verb": "TEACH",
  "v2": "taught",
  "v3": "taught",
  "sit": "Описание ситуации.",
  "success": "Текст при правильном ответе.",
  "fail": "Текст при ошибке."
}
```

2. Запустите `./src/build.sh`
3. Откройте `index.html` в браузере

## Требования

- Bash
- Python 3
- Браузер для открытия HTML (Chrome, Firefox, Safari, Edge)
